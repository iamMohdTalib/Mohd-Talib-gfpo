## About

I build full-stack JavaScript applications — REST APIs and data models on the Node side, component architecture and state management on the React side, and the deployment pipeline in between.

- Currently working on a production **accounting and financial reporting platform**: pivot reporting, KPI dashboards, ledger and master-data management.
- Strongest in **complex data-heavy UI** — virtualised tables, pivot builders, filtering and column systems, and the state management that keeps them fast.
- Comfortable owning a feature from schema design through API to shipped interface.
- Currently going deeper into **applied AI engineering** — retrieval systems, evaluation harnesses, and agent architectures on top of LLM APIs.
